# 绕口令材料包（练嘴热身）

用法见 [PROTOCOL.md](../PROTOCOL.md)：上场前选 **1 慢 + 1 常**；加强版再换一组声母冲突。

标注说明：
- ★ 默认推荐（短、好记、升温快）
- 气口用 `/` 标出；没标的可按逗号停

---

## A. 基础激活（每日首选）

### A1 ★ 四与十（平翘舌）

```text
四是四，十是十，
十四是十四，四十是四十。
谁能说准十四、四十、四十四，
谁来试一试。
```

慢速要点：`四/十` 舌位分开，不要糊成一个音。

### A2 ★ 葡萄皮（唇齿连续）

```text
吃葡萄不吐葡萄皮，
不吃葡萄倒吐葡萄皮。
```

常速要点：`葡萄` 两字轻重要稳，不要越说越小声。

### A3 花椒（开合口）

```text
粉红墙上画凤凰，
凤凰画在粉红墙。
红凤凰，粉凤凰，
红粉凤凰，花凤凰。
```

适合早上口干、开合发紧时。

## B. 声母冲突组（加强版换练）

### B1 h / f

```text
黑化肥发灰，灰化肥发黑。
黑化肥发灰会挥发，
灰化肥挥发会发黑。
```

### B2 n / l

```text
牛郎恋刘娘，刘娘念牛郎；
牛郎年年念刘娘，
刘娘年年恋牛郎。
```

### B3 s / sh

```text
石狮子，涩柿子，
吃柿子，看狮子；
狮子是石狮子，
柿子是涩柿子。
```

### B4 j / q / x（细音）

```text
七巷漆匠和西巷锡匠，
七巷漆匠用了西巷锡匠的锡，
西巷锡匠拿了七巷漆匠的漆。
```

## C. 防「急着出口断句错」专用

这类绕口令故意有并列结构，练的是：**宁可慢，不要在错误位置换气。**

### C1 ★ 班门弄斧式断句

```text
我说 / 你说 / 他说 / 都别抢说；
先听完 / 再开口 / 一句一事 / 说完再换。
```

（原创短句，专为热身；可当绕口令节奏练。）

### C2 数字阶梯（越往后越容易抢气）

```text
一二三，三二一，
一二三四五六七，
七六五四三二一。
```

要求：每行只在行末换气；行中不准用「呃」填。

## 自检口令

练完问自己三句：

1. 有没有字是「带过」而不是咬清的？  
2. 加速后有没有肩膀跟着紧？有 → 降速。  
3. 是否为了赶完而在错误位置换气？（对应旧坑：短句错误后卡死）
