# 顺口溜材料包（练嘴热身）

顺口溜负责两件事：**记住协议步骤**，以及**给脑子一个固定槽位**（防急着乱说）。  
跟读时要出声；默念不算热身。

---

## 1. ★ 协议总口令（必背）

```text
先热嘴，再热脑，最后才把事情讲。
绕口令，贯口气，三句话里定方向。
```

对应 PROTOCOL：绕口令 → 贯口 → 三句结构。

---

## 2. ★ 三句结构口令（脑嘴对齐段）

```text
先说结果，再说因，最后落点给行动。
一句一事别塞馅，卡壳先停再复述。
```

变体（职场汇报）：

```text
结果同步要干脆，原因只留一条根；
行动写清谁来做，别把委屈堆上门。
```

---

## 3. 换气 / 停顿口令（针对「不会换气」）

```text
话说一半可以停，停不是怂是换气；
复述一句找节奏，找着气口再接戏。
```

急着出口、断句错误时用：

```text
欲速则不达，出口先断对；
断错立刻停，重来不为罪。
```

---

## 4. 情绪底座口令（热身前后各念一遍）

```text
语言是工具，不是英雄片；
目的先想清，情绪再靠边。
温着开场别过热，过热容易把脚绊。
```

冲突前加半句：

```text
事实一层，情绪一层，利益一层分开谈。
```

---

## 5. Small talk 启动口令

```text
先判关系再开口，提问开场少自嗨；
两分钟故事别超长，夸人夸到细节来。
```

---

## 6. 即兴启动口令

```text
先立目的一句话，再给例子撑住它；
接不上话先总结，总结完了再发花。
```

「发花」= 补充观点；接话困难时优先「做总结偷时间」。

---

## 7. 结束验收口令（录音回放时对照）

```text
字咬清，气不断，句不抢；
三件过了再上场。
```

---

## 怎么用（不要当朗诵比赛）

| 场景 | 用法 |
|------|------|
| 每日热身 §④ | §1 + §2 各跟读 2 遍，再压今天的三句 |
| 电话前 | §3 换气口令 1 遍 → 直接拨 |
| 感到表演焦虑 | §4 情绪口令，降 ego |
| 无聊局 | §5，提醒自己提问开场 |
| 被追问发懵 | §6，先总结对方的话 |

顺口溜说顺 ≠ 会表达；它只是**把正确顺序焊进肌肉记忆**。焊牢之后，上场靠三句内容，不靠继续背溜。
